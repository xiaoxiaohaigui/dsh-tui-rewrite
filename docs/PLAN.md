## 0. 需求边界（不变式）

**做**：用户**手动**改写会话历史中助手回复的**文本**；下一轮模型看到改写后的内容；
append-only 日志原文不变。

**不做**：任何自动改写、拒绝检测、模式匹配、自动替换策略；工具调用参数与
`tool/result` 内容不做（用户 2026-10-15 决策）。

**硬约束**（每个阶段都必须成立的验收前提）：

| 编号 | 约束 | 判据 |
|---|---|---|
| C1 | 模型可见文本变为改写内容 | `deriveMessages()` 回读等于新文本 |
| C2 | 消息数量与身份不变 | 消息数不变；目标仍挂原 `seq` |
| C3 | 邻居不受影响 | 其余消息逐字节相同 |
| C4 | 日志原文不变 | `eventAt(seq).data.message` 仍是原文 |
| C5 | 事件不携带 surface 元数据 | `surfaceOp` / `sourceEventSeqs` 均为 undefined |
| C6 | 插件缺失时日志可读 | 无投影重开不抛错，原文浮现 |
| C7 | 失败可见 | 投影未注册时必须显式告警，不得静默失效 |
| C8 | 不拖垮启动 | 插件任何失败都不得导致 profile 无法启动 |

### 阶段 1b —— 列表模式（键盘 + 鼠标）

**目标**：在场景内用键盘或鼠标选中一条助手回复。

**范围**：`↑↓`/`jk` 移动；`Enter` 进入编辑；鼠标 `onClick` 选中、
`onWheel` 滚动（含 `wheelRows` 归一化）；视口跟随选中项；
hover 状态为**组件局部** state + 稳定 id 作 key（宿主不给被卸载节点发 `onMouseLeave`）。

**验收**：

- [ ] B1 键盘可在全部目标间移动，选中项高亮
- [ ] B2 长列表滚动时选中项始终可见
- [ ] B3 鼠标点击任意行即选中该行
- [ ] B4 滚轮按「格」步长滚动，横向事件不触发纵向滚动
- [ ] B5 hover 高亮不漂移（折叠/滚动/重排后仍指向指针所在行）

**测试策略**：`wheelRows` 与视口窗口计算为纯函数，可自动化；
交互手感在真机验证。

### 阶段 1c —— 编辑模式与提交

**目标**：进入某条回复的编辑模式，改完提交，模型看到新文本而日志不变。

**范围**：多行编辑器（输入/退格/换行/方向/Home/End/粘贴）；`Ctrl+S` 提交、
`Esc` 取消；提交后刷新清单并提示；`Ctrl+S` 亦可用于列表选中项。
**不做**：语法高亮、软换行折行（超出本阶段）。

**验收**：

- [ ] C1 进入编辑模式时预填该消息**当前模型可见**的文本
- [ ] C2 光标移动、插入、删除、换行行为正确（含 CJK 与 emoji 边界）
- [ ] C3 多字符粘贴整段插入，不丢字符
- [ ] C4 提交后 C1–C5 硬约束全部成立（自动化）
- [ ] C5 未修改即提交时不追加事件
- [ ] C6 提交失败（如日志不可写）时给出可见错误，不静默
- [ ] C7 `Ctrl+S` 被终端吃掉时，可从列表选中项触发同一提交路径

**测试策略**：编辑器核心抽成纯函数（插入/删除/光标/行列换算）后单元测试覆盖；

## 3. 测试与验证基建

**一条命令**：`bash test-harness/run.sh`（或 `npm test`）。

| 层 | 位置 | 覆盖 | 何时跑 |
|---|---|---|---|
| 单元 | `test-harness/test/*.test.mjs` | 投影改写规则、场景纯函数、清单枚举边界 | 每次改动 |
| 集成 | 同上（`plugin.test.mjs`） | 真实 cordis 图：注册、拒重复、顺序竞态、append→derive、卸载 | 每次改动 |
| 可读报告 | `test-harness/report.mjs` | 端到端契约的可读输出 | 需要人看时 |
| 真机 | 见第 4 节清单 | 渲染、输入、鼠标、视觉 | 每个阶段收尾 |

**解析夹具**（`build-fixture.mjs`）：用 **junction** 而非 symlink，
使 Node 按真实路径解析、各包自身兄弟依赖可达 —— 等价于包管理器布局，
无需 `--preserve-symlinks`。

**真机挂载**（`mount.mjs` / `unmount.mjs`）：幂等、自动备份、一键回滚。
真机验证的前置条件是**始终可回滚**。

**日志约定**：`DSH_TUI_REWRITE_DEBUG` 指向文件（或设 `1` 用默认路径
`~/.dsh-tui/dsh-tui-rewrite.log`）时，场景挂载、目标枚举、提交与失败写入 JSONL。
全屏界面里 stderr 不可见，这是唯一的现场证据通道。

**样本会话**：默认取本机一个真实中等规模日志；用 `DSH_REWRITE_SAMPLE` 覆盖路径。
