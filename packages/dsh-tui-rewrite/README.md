# dsh-tui-rewrite

⛔ **Alpha — 尚未可用。** 插件本体还有一个未修复的 P1：用户提交过一次改写之后，
该会话会**无法再被恢复**。**在修复版发布之前，请不要把它挂到日常 profile 上使用。**

dsh-tui 插件：允许用户**手动**改写会话历史中助手回复的文本。改写后下一轮对话
模型看到的是改写后的内容，而 append-only 的持久化日志原文不变。
