# dsh-tui-rewrite

⛔ **Alpha — 尚未可用。** 插件本体尚有一个未关闭的 P1：提交过一次改写后，该会话
会无法再被恢复（`REVIEW.md` R-019）。**在修复并发布新版本之前，请不要把它挂到
日常 profile 上使用。**

dsh-tui 插件：允许用户**手动**改写会话历史中助手回复的文本。改写后下一轮对话
模型看到的是改写后的内容，而 append-only 的持久化日志原文不变。
